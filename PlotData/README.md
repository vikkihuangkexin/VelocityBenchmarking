# PlotData

This folder contains the input data tables used by the ranking and figure scripts.

- `accuracy/real/` and `accuracy/sim/`: accuracy metric tables.
- `scalability/`: Docker scalability workbooks, including the 2k/5k HVG workbook.
- `stability/`: downsampling and batch-run stability inputs.
- `usability/`: usability score workbook and summary table.
- `Results/` and `Figures/`: generated by the scripts and ignored by Git by default.
