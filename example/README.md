### Sample file and simulated data

**Sample file contents**  
The example/sample file includes a simple table with the following columns:

- **data** — dataset index or short label  
- **ID** — dataset identifier  
- **Reference** — literature source or citation for the dataset  
- **GSE-code** — GEO accession (when available)

Example (illustrative):

| data | ID   | Reference            | GSE-code  |
|------|------|----------------------|-----------|
| 1    | 8    | Author et al., Year  | GSEXXXXX  |
| 2    | 25   | Author et al., Year  | GSEYYYYY  |
| 3    | 51   | Author et al., Year  | GSEZZZZZ  |

Replace `...` and `GSEXXXXX` with your actual dataset names and accession codes.
